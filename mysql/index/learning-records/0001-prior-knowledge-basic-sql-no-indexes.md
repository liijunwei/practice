# Prior knowledge: basic SQL, no index experience

**Evidence**: user's self-assessment in the mission-setting interview ("Comfortable with basic SQL").

**Implications**: future sessions can assume SQL syntax fluency and should not re-teach query writing. Hands-on exercises may use moderately complex queries without explaining the SQL itself; teaching effort goes entirely to index and performance concepts. See [[MISSION.md]] for the goal and scope.
